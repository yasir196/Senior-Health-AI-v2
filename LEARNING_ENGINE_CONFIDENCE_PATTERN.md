# Learning Engine: Evidence Maturity + Pattern Learning

Added without changing the existing import/DB/project workflow.

Evidence maturity:
- MATURE: >=100 views OR >=1,000 thumbnail impressions
- DEVELOPING: >=30 views OR >=300 thumbnail impressions
- EARLY: below both developing thresholds

EARLY videos stay visible but are excluded from winner/loser reference learning.

Pattern Learning compares repeated title structures among learning-eligible videos:
- After/Over age framing
- Number/list framing
- Question framing
- Mistake framing
- Warning framing
- Action framing

Pattern results are descriptive correlations, not causal claims.
