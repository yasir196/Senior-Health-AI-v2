# 06 — Thumbnail Blueprints

> Permanent internal documentation. Senior Health YouTube Production System.
> This document is standalone and self-contained.

---

## 1. Master Recipe

High-contrast mobile-readable copy + one dominant visual idea + optional presenter + restrained accent cues.

There is no universal 2–5-word rule, no mandatory arrow/circle, and no mandatory single-object rule. Use current ACTIVE channel packaging evidence when applicable, while preserving medical safety, senior comprehension, and the current title's core subject/promise.

| Parameter | Guidance |
|-----------|----------|
| Background | Strong contrast; dark navy/near-black is a common channel pattern when supported by ACTIVE evidence |
| Text length | As short as possible without becoming cryptic; no universal word-count cap |
| Presenter | Optional; when used, place according to applicable ACTIVE channel examples and the 3x3 composition map; clearly non-clinician |
| Hero treatment | One dominant visual idea; a grouped set may count as one hero for list titles |
| Signal icons | Optional and restrained; use only when they clarify a non-obvious relationship |

---

## 2. Core Layout Families

These are starting families, not mandatory topic-to-layout mappings.

| ID | Layout | Useful When | Components |
|----|--------|-------------|------------|
| L1 | Food/Object Hero + Clear Question + Presenter | Food / practical topics | Recognizable hero, explicit subject anchor, curious presenter |
| L2 | Body/Symptom Context + Clear Question + Presenter | Symptom / function topics | Respectful non-graphic context, clear copy, concerned-curious presenter |
| L3 | Product/Label Detail + Question | Product qualification topics | One product/detail only when it represents the whole-video promise |
| L4 | Supported Action + Clear Instruction | Mobility / exercise topics | Safe action, stable support when needed, concise action copy |
| L5 | Grouped List Hero + Subject-Anchored Gap | List topics | One visually unified group preserving list-level promise |

Choose the family from the immutable title, approved evidence, medical boundaries, and applicable ACTIVE channel patterns. Never force a layout merely because the topic belongs to a broad category.

---

## 3. Color and Contrast

- Prioritize mobile contrast and hierarchy over fixed color formulas.
- Yellow/white on dark navy or near-black is a strong channel-compatible treatment when supported by current ACTIVE evidence.
- Red is an accent, not a mandatory danger signal.
- Green checks, blue trust bands, circles, arrows, and glows are optional; never add them merely to satisfy a template.
- Never use color/glow to imply a medical effect, cure, repair, circulation improvement, or biological pathway that the evidence does not support.

---

## 4. Presenter Positioning

- Presenter is an optional health educator / relatable older adult, never doctor-coded by default.
- When used, presenter placement should follow applicable ACTIVE channel examples and the 3x3 composition map while leaving enough room for the hero and copy. Do not enforce a fixed presenter-width percentage.
- Gaze may face the viewer or route attention toward the hero.
- Expression should be clear but believable: concerned-curious, thoughtful, surprised, reassuring, or action-focused as appropriate.
- Avoid white coats, badges, stethoscopes, exaggerated medical authority, or theatrical suffering unless explicitly justified and compliant.

---

## 5. Hero / Object Positioning

- Use one dominant visual idea, not necessarily one physical object.
- For list titles, a unified board/tray/group can preserve the complete list promise and still function as one hero.
- A single-item close-up cannot win a multi-item/list title when it makes the whole video look like a narrow side-topic unless that item is an obvious gateway into the full list.
- Hero objects should be large, recognizable, and separated cleanly from copy and presenter.
- Avoid decorative clutter and abstract relationships that require explanation.

---

## 6. Standalone Semantic Promise Lock

The thumbnail may be understood before the viewer meaningfully reads the title. Therefore the finished thumbnail must communicate the video's core subject/category on its own in about one second.

**Complementary does not mean disconnected.** The overlay may withhold the answer or add a different information gap, but the combination of prominent text + dominant hero must still identify the title's central subject/promise.

Before a concept can win, perform this cold-viewer test:

> Hide the title. Looking only at the proposed thumbnail, what would a 60+ viewer say this video is mainly about?

The answer must substantially match the title's core subject/category. If several unrelated interpretations are equally plausible, the concept is too ambiguous and cannot win.

Examples of failure:

- A calcium-rich-food video whose thumbnail reads only `WHAT MAKES THESE COUNT?` while showing generic foods can look like general grocery/health/protein advice. The prominent copy or dominant visual must make the calcium/bone-food subject unmistakable without claiming a bone outcome.
- A circulation video that becomes only a generic drink-label thumbnail.
- A three-exercise mobility video that looks like a single chair-product video.

Safe repair principle: add the **minimum explicit subject anchor** needed for standalone comprehension. For example, `WHAT MAKES THESE CALCIUM-RICH?` can preserve curiosity while anchoring the subject. Do not repeat the whole title and do not introduce a stronger medical claim.

### Neutral context cue vs medical outcome claim

Do not blanket-ban an entire subject merely because outcome imagery could be misleading. Distinguish:

- **Allowed when accurate and non-claiming:** neutral contextual cues that help identify the subject/category.
- **Not allowed:** before/after repair, reversal, treatment, cure, guaranteed improvement, food-to-organ transformation arrows, glowing biological effects, fake X-rays, diagnosis badges, or other outcome symbolism not supported by evidence.

For bone-health topics, a neutral non-diagnostic bone-context cue may be considered only if it improves immediate subject recognition and cannot reasonably imply rebuilding, reversal, osteoporosis diagnosis, fracture prevention, or treatment. Food-to-bone arrows and transformation effects remain prohibited.

---

## 7. Object Hierarchy / Eye Path

Engineer a simple reading order. A useful default is:

1. Dominant subject-anchored question/payoff phrase
2. Hero visual
3. Presenter/face when used
4. Secondary qualifier/accent only if necessary

At mobile size, avoid more than roughly three primary attention demands.

## 8. Packaging / Visual Rules

| ID | Rule | Severity |
|----|------|----------|
| V1 | Dominant copy readable at about 120px feed width | Block |
| V2 | Standalone thumbnail communicates the title's core subject/category | Block |
| V3 | Whole-video promise is preserved; side-detail drift cannot win | Block |
| V4 | One dominant visual idea with clear relationships | Block |
| V5 | Presenter is non-clinician and expression is believable when present | Block |
| V6 | Text is not shortened into cryptic shorthand merely to hit a word count | Block |
| V7 | Arrow/circle/check/glow is optional and must earn its place | Warn |
| V8 | Medical outcome symbolism must be evidence-supported and non-misleading | Block |
| V9 | Applicable ACTIVE channel packaging patterns are used as associations, not guarantees | Block |

---

## 9. Pre-Publish Thumbnail Checklist

- [ ] At 120px feed width, the dominant text is readable.
- [ ] With the title hidden, a cold 60+ viewer can identify the video's core subject/category in about one second.
- [ ] The overlay creates curiosity without requiring the title to decode basic meaning.
- [ ] The dominant hero represents the whole-video promise, especially for list titles.
- [ ] The composition has one dominant visual sentence rather than a collage of competing cues.
- [ ] Presenter styling is non-clinician and believable when a presenter is used.
- [ ] Medical context cues do not imply diagnosis, treatment, cure, reversal, prevention, or guaranteed outcomes.
- [ ] Text length follows comprehension and current ACTIVE evidence, not an arbitrary word-count cap.
- [ ] Any arrow/circle/check/glow has a specific purpose and is not redundant.
- [ ] Historical channel patterns are adapted only where applicable and never override semantic fit or safety.

A concept that fails standalone semantic comprehension, whole-video promise coverage, or medical safety is not eligible to win even if its internal Packaging Score is otherwise high.
