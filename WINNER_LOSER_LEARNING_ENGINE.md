# Winner / Loser Learning Engine

The Analytics page now includes a dedicated Learning Engine.

It uses each video's latest Content/Performance snapshot and the channel's own
median CTR and median Average Percentage Viewed.

Categories:
- STRONG
- PACKAGING OPPORTUNITY
- CONTENT HOLD OPPORTUNITY
- PACKAGING + CONTENT

The engine provides:
- current channel baselines
- actionable priority summary
- winner reference set
- packaging opportunities
- content-hold opportunities
- full-review candidates
- relative learning score for winner ranking

The engine does not claim exact scene-level causes without retention-curve data.
It does not modify titles, scripts, project files, Medical Gates, or production data.
