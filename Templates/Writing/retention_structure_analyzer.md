# Retention Structure Analyzer

Analyze narrative structure only. Do not research, add medical claims, or use runtime as a pass/fail gate.

## Material Delta Contract
For every recurring core idea after its primary explanation, record **MATERIAL DELTA VS PRIMARY**. A changed example, food, section, hypothetical, wording, or repeated scope reminder is not automatically new value. Name the concrete new viewer knowledge, decision, mechanism, consequence, evidence, or action. If none exists, mark the recurrence for CUT/MERGE unless it is the single concise final recap.

Keep density separate from progression. Dense material is not automatically a hard failure when it adds supported new viewer value. Runtime is advisory only.
