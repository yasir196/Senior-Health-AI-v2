# ACTIVE CHANNEL SCRIPT RULES

These rules were learned automatically from repeated retention-linked script patterns.
Apply them to future scripts unless they conflict with the immutable winning title,
approved research/evidence, Medical Gate requirements, or required safety language.
They guide delivery/structure only; they must never weaken medical accuracy or required cautions.

## Rule 1: Care / safety section may be interrupting momentum
- **Instruction:** Keep required safety guidance intact, but make it concise, non-repetitive, and clearly connected to the practical point around it.
- **Evidence:** 22 learning-eligible videos / 45 retention events / avg change -3.22 points

## Rule 2: Dense information delivery
- **Instruction:** Reduce simultaneous ideas and make the hierarchy clearer; preserve the strongest takeaway and supporting evidence.
- **Evidence:** 12 learning-eligible videos / 13 retention events / avg change -18.42 points

## Rule 3: Delayed payoff / preamble in the opening
- **Instruction:** Deliver a concrete piece of the promised value earlier, then add only the setup or qualification needed to understand it.
- **Evidence:** 7 learning-eligible videos / 7 retention events / avg change -14.90 points

## Rule 4: Repetition / restatement signal
- **Instruction:** Remove redundant restatement and keep the next sentence only when it adds a new distinction, example, consequence, or action.
- **Evidence:** 5 learning-eligible videos / 27 retention events / avg change -4.87 points

## Rule 5: Qualification / safety interruption
- **Instruction:** Preserve required safety context, but make the useful point easy to identify and avoid duplicating the same qualification.
- **Evidence:** 3 learning-eligible videos / 3 retention events / avg change -7.00 points
