# YouTube Reference Discovery for New Thumbnails

For a new video/project, the thumbnail intelligence stage should not depend only on this channel's history.

## Discovery order
1. Use eligible channel winners as the primary learned prior.
2. Search YouTube for the **same topic**.
3. Expand to the **same category** when useful.
4. Search across channels; do not restrict discovery to the current channel.
5. Outliers are useful but **not mandatory**.

## What to inspect
For every useful external example, inspect the **video title and thumbnail together**. Capture the full title, thumbnail reference, channel, video ID, available performance/context fields, topic/category match, and any evidence supporting an outlier label.

## Outlier rule
Do not label a video an outlier merely because it has many views. An outlier label requires comparative evidence against an appropriate baseline. If that evidence is unavailable, keep the example as a relevant reference without calling it an outlier.

## How external examples are used
External YouTube examples broaden concept, composition, text-treatment, and title-thumbnail relationship ideas. They are reference evidence, not automatic rules.

Priority remains:
**eligible channel winners → relevant YouTube references → final concept direction**.

The supplied new-project title remains immutable. Loser patterns remain in the repair lane only. Do not copy another creator's thumbnail verbatim.
