# Loser Repair UI

A loser card should expose: original thumbnail, immutable title, full extracted/reviewed thumbnail text, evidence for lower-CTR grouping, same-category winner evidence, proposed replacement text, visual direction, and a fully editable image-edit prompt.

The prompt is the primary handoff. The user may copy it into any image generator. No built-in generation provider is required.

If generation integration is added later, it must be explicitly enabled and must never replace historical/published evidence automatically.
